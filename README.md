# my-vue-hub

Application Vue.js qui centralise leçons et exercices d'apprentissage de Vue.

## Stack

- [Vue 3](https://vuejs.org/)
- [Vite](https://vite.dev/)
- JavaScript
- [Bun](https://bun.sh/)

## Installation

```bash
git clone https://github.com/kdauvergne/my-vue-hub.git
cd my-vue-hub
bun install
```

## Scripts

```bash
bun run dev
bun run build
bun run preview
```

## Contenu

- **Leçons** : notions clés de Vue
- **Exercices** : mises en pratique associées à chaque leçon
